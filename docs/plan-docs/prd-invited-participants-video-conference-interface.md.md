# Plan: Shared video conference interface for invited meeting participants

**PRD:** docs/prd-invited-participants-video-conference-interface.md
**Дата:** 2026-08-20

## Фазы реализации

### Фаза 1: Frontend — вход в конференцию и видео-грид (Tracer Bullet)

**Цель:** Участник с доступом видит кнопку «Войти в конференцию» на странице встречи, попадает на страницу конференции, получает токен, подключается к комнате и видит видео/аудио участников. Это минимальный рабочий путь всей фичи.
**Затрагивает:** frontend
**Задачи:**

- [ ] Добавить зависимость `@livekit/components-react` (и `@livekit/components-styles`) в `apps/web`
- [ ] Добавить в `src/lib` функцию получения токена конференции через `POST /meetings/:id/conference/token` (Bearer-токен, обработка 401/403/404) с типами
- [ ] На странице `meetings/[id]` добавить кнопку «Войти в конференцию» (видна всем, у кого есть доступ) с переходом на `/meetings/[id]/conference`
- [ ] Создать страницу конференции `/meetings/[id]/conference`: получение токена, инициализация `LiveKitRoom`, подключение к комнате, рендер `ParticipantTile`-грида с собственной плиткой, помеченной «Это вы»
- [ ] Написать unit-тесты: рендер кнопки на странице встречи, получение токена (успех и 401/403/404), подключение к комнате и отображение участников

**Когда готова:** Участник с доступом нажимает «Войти в конференцию» на странице встречи, подключается к комнате и видит видео/аудио всех участников (включая себя с пометкой «Это вы»).

### Фаза 2: Frontend — управление медиа и экранный шаринг

**Цель:** Участник может отключать/включать микрофон и камеру (состояние видно на плитках) и показывать свой экран остальным.
**Затрагивает:** frontend
**Задачи:**

- [ ] Панель управления в конференции: кнопки mute/unmute микрофона и включения/выключения камеры с отображением состояния на своей плитке
- [ ] Отображать состояние mute/камеры на плитках других участников (из `trackPublication`)
- [ ] Кнопка «Поделиться экраном» с запуском/остановкой шаринга (`createLocalScreenTracks` / LiveKit) и отображением шаримого экрана у остальных
- [ ] Обработка отказа в разрешениях микрофона/камеры с понятным сообщением (graceful fallback — участник остаётся в комнате)
- [ ] Написать unit-тесты: переключение mute/камеры и отражение на плитках, запуск/остановка шаринга, обработка отказа разрешений

**Когда готова:** Участник включает/выключает микрофон и камеру (состояние видно на всех плитках), показывает свой экран остальным и может его остановить; при отказе в разрешениях получает понятное сообщение и остаётся в комнате.

### Фаза 3: Frontend — чат комнаты и выход из конференции

**Цель:** Участники общаются в общем чате комнаты; выход возвращает на страницу встречи, повторный вход работает.
**Затрагивает:** frontend
**Задачи:**

- [ ] Чат комнаты (панель сообщений): отправка и отображение сообщений, видимых всем участникам комнаты (эфемерный, не сохраняется после встречи)
- [ ] Кнопка «Выйти» с отключением от комнаты и возвратом на страницу `/meetings/[id]`; повторный вход работает корректно
- [ ] Обработка ошибок подключения: отказ в токене, LiveKit недоступен — понятные сообщения с возможностью вернуться на страницу встречи
- [ ] Написать unit-тесты: отправка и отображение сообщений чата, выход и возврат на страницу встречи, обработка ошибок подключения

**Когда готова:** Сообщения чата видны всем участникам комнаты; выход возвращает на страницу встречи и повторный вход работает; ошибки токена/недоступности LiveKit показываются понятными сообщениями. Линт и формат чистые.
