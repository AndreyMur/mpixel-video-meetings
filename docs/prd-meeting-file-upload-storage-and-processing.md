# PRD: Загрузка файла встречи для хранения и обработки с отображением внутри встречи

**Дата**: 13 августа 2026
**Статус**: Draft

## Цель

Позволить пользователю прикреплять файлы к своей встрече (записи, презентации, документы), надёжно хранить их в объектном хранилище и обрабатывать в фоне (лёгкие метаданные, превью). Результат — файлы и их статус обработки видны прямо на странице встречи, доступной только её владельцу.

## Пользовательские сценарии

- Пользователь открывает страницу своей встречи и загружает файл -> файл сохраняется, появляется в списке с именем, типом, размером и датой загрузки.
- Пользователь загружает аудио/видео запись встречи -> файл автоматически обрабатывается: извлекается длительность, для видео генерируется превью; статус меняется с «обработка» на «готово».
- Пользователь загружает документ (PDF) -> извлекается количество страниц и генерируется превью страницы.
- Пользователь открывает встречу -> видит все свои загруженные файлы и текущий статус обработки каждого.
- Пользователь загружает файл в чужую встречу (не владелец) -> получает отказ в доступе.
- Пользователь удаляет файл -> файл исчезает из списка и из хранилища.

## В скоупе

- Загрузка файла в конкретную встречу через multipart-запрос (только владелец встречи).
- Хранение файлов в объектном хранилище (S3-совместимое, Minio/S3).
- Модель данных: файл встречи (имя, тип, размер, статус обработки, ссылка, связь с встречей и владельцем).
- Список файлов встречи с метаданными и статусом обработки.
- Удаление файла (из БД и хранилища).
- Фоновая обработка файла: извлечение лёгких метаданных (длительность медиа, страницы PDF) и генерация превью (кадр видео, первая страница PDF).
- Асинхронный пайплайн обработки с отслеживаемым статусом (uploaded -> processing -> ready | failed).
- Страница деталей встречи в веб-приложении: список файлов + форма загрузки.
- Доступ: только владелец встречи видит и управляет файлами.
- Лимиты: файлы до 50 МБ, разрешённые форматы — документы (pdf, txt, doc, docx, xls, xlsx, ppt, pptx) и медиа (mp3, wav, m4a, mp4, webm).

## Не в скоупе

- Просмотр/воспроизведение файлов прямо на странице встречи (только скачивание по ссылке).
- Транскрипция аудио/видео (создание и хранение транскрипта) — отдельная фича после базового пайплайна.
- Превью и метаданные для Office-документов (doc/docx/xls/xlsx/ppt/pptx) — требуют LibreOffice, отдельная фича.
- Общий доступ к файлам для участников встречи (поле participants не даёт прав).
- Поиск, фильтрация и сортировка файлов.
- Версионирование и перезапись файлов.
- Возобновляемая загрузка и загрузка папками.
- Ограничение суммарного объёма хранилища на пользователя.

## Технические ограничения

- Объектное хранилище в текущей инфраструктуре отсутствует — нужно добавить сервис (например, контейнер Minio в docker-compose) и конфигурацию доступа.
- Обработка файлов выполняется асинхронно и не должна блокировать ответ на загрузку.
- В очереди/воркере нет инфраструктуры — требуется добавить (например, Redis + воркер).
- Загрузка идёт через существующий прокси веб-приложения `/api/*` на бэкенд.
- Размер и формат файла проверяются на бэкенде, а не только в UI.
- Файлы привязаны к встрече и владельцу; любые операции проверяют принадлежность.

## Критерии готовности

- [ ] Владелец встречи может загрузить файл до 50 МБ разрешённого формата через страницу встречи; файл сохраняется в объектном хранилище, а его запись — в БД, связанная с встречей.
- [ ] Загрузка файла в несуществующую встречу или встречу другого пользователя возвращает 403/404 и ничего не создаёт.
- [ ] Загрузка файла больше 50 МБ или неразрешённого формата отклоняется с понятным сообщением об ошибке.
- [ ] Сразу после загрузки файл появляется в списке встречи с именем, типом, размером, датой и статусом «обработка».
- [ ] После завершения фоновой обработки статус файла меняется на «готово»; для видео и PDF создано превью, извлечены доступные метаданные (длительность для медиа, страницы для PDF).
- [ ] При сбое обработки статус файла меняется на «ошибка», файл остаётся в списке.
- [ ] Владелец может скачать файл по ссылке и удалить его; после удаления файл исчезает из списка и из хранилища.
- [ ] Пользователь, не являющийся владельцем встречи, не видит и не может запросить список файлов встречи.
- [ ] Страница деталей встречи доступна по прямой ссылке и показывает список файлов и форму загрузки.
- [ ] Список файлов подгружается с бэкенда через защищённый JWT-эндпоинт.
