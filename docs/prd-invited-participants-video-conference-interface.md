# PRD: Shared video conference interface for invited meeting participants

**Дата**: 2026-08-20
**Статус**: Draft

## Цель

Дать участникам встречи с доступом простой путь войти в общую видео конференцию и участвовать в ней: видеть и слышать друг друга, шарить экран и общаться в чате.

## Пользовательские сценарии

- Пользователь с доступом открывает страницу встречи -> видит кнопку «Войти в конференцию»
- Пользователь нажимает кнопку -> открывается страница конференции; после запроса разрешений он в комнате
- Участник видит видео всех остальных -> грид участников, собственная плитка помечена «Это вы»
- Участник отключает микрофон/камеру -> состояние видно на его плитке
- Участник шарит экран -> остальные видят его экран вместо видео
- Участник пишет сообщение -> сообщение видно всем в комнате
- Участник выходит -> возвращается на страницу встречи

## В скоупе

- Кнопка «Войти в конференцию» на странице встречи — видна всем с доступом
- Страница конференции по роуту `/meetings/[id]/conference`
- Запрос разрешений микрофон/камеры с понятным отказом (graceful fallback)
- Грид видеоучастников, индикация «вы», mute/unmute, включение/выключение камеры
- Экранный шаринг (с остановкой)
- Текстовый чат комнаты (эфемерный, не сохраняется после встречи)
- Выход из конференции с возвратом на страницу встречи
- Обработка ошибок: отказ в токене, LiveKit недоступен, отказ разрешений

## Не в скоупе

- Запись конференции и её воспроизведение
- Модерация (кик, mute участников организатором) — все участники равноправны
- Индикация «кто сейчас в комнате» на странице встречи до входа
- Подключение гостей без аккаунта

## Технические ограничения

- LiveKit должен быть достижим из браузера (docker-compose пробрасывает порты 7880/7881)
- JWT для подключения получается через API перед инициализацией комнаты
- `getUserMedia` требует безопасного контекста (HTTPS или localhost) — в разработке localhost
- Одна комната = одна встреча; участник подключается под своим `userId`

## Критерии готовности

- [ ] Кнопка «Войти в конференцию» видна всем с доступом и ведёт на страницу конференции
- [ ] Страница конференции подключается к комнате встречи и отображает видео/аудио участников
- [ ] Mute/unmute и вкл/выкл камеры работают и отражаются на плитках
- [ ] Экранный шаринг виден остальным участникам и останавливается по кнопке
- [ ] Сообщения чата видны всем участникам комнаты
- [ ] Отказ разрешений и ошибки подключения показываются понятными сообщениями
- [ ] Выход возвращает на страницу встречи; повторный вход работает
- [ ] Линт и формат чистые; unit-тесты на компоненты (кнопка входа, чат) где применимо
